# Subjonctif — практикум

Тренажёр по французскому subjonctif: 877 вопросов, теория, таблицы глаголов и 100 фраз на перевод с русского.
Страница защищена паролем: содержимое зашифровано (AES-GCM) и расшифровывается в браузере.

## Как обновить

1. Пересобрать локальный файл «Subjonctif — практикум.html».
2. `python make_site.py "Subjonctif — практикум.html" . "<пароль>"` (нужен пакет `cryptography`).
3. `git commit -am "update" && git push` — через минуту GitHub Pages покажет новую версию.

Сменить пароль = пересобрать с новым паролем: у всех, кто его запомнил, страница попросит ввести новый.
